### Исправлено подтверждение перезапуска
- «Проверить сейчас» передаёт запрос службе обновлений напрямую, не дожидаясь очередной фоновой проверки. Исправлена загрузка при кириллице в пути профиля Windows.
- После загрузки и проверки подписи показывается окно «Перезапустить Reload Assistant?» с кнопками «Да» и «Нет». Если основное окно открыто, запрос центрируется относительно него. При недоступности фирменного окна используется системное подтверждение.
- В настройках видны этапы проверки. Для готового обновления можно открыть подтверждение повторно. «Нет» оставляет приложение открытым, «Да» перезапускает только Reload Assistant. Для актуальной версии перезапуск не предлагается.
