- В редакторе сценариев шаги «Запустить приложение» и «Закрыть приложение» используют полный список программ, обнаруженных на компьютере, без фильтра популярности. Есть поиск по названию и кнопка «Выбрать .exe…» для программ без ярлыка.
- В «Команды → Команды агента → Сценарий по описанию» можно назвать программу из этого же полного списка или добавить её из EXE. Например: «Открой 7-Zip File Manager».
- Обычный каталог команд остаётся компактным. Сценарий хранит название приложения и каждый раз сверяет его с актуальным списком; если программа исчезла, другая вместо неё не запускается.
