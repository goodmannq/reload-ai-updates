### Установка и оформление
- Два варианта загрузки: **Reload.AI.Setup.exe** — синий установщик для Windows 10/11 x64; **Reload.AI.exe** — самостоятельное приложение. Автообновления по-прежнему используют обычный EXE.
- Установщик позволяет выбрать папку, добавляет ярлык в меню «Пуск» и по умолчанию запускает приложение по завершении. Загружает эту версию по HTTPS и сверяет SHA-256; если рядом лежит подходящий Reload.AI.exe, интернет для установки не требуется.
- В папке установки находятся `sounds` с 53 WAV и `themes` с примером JSON. Повторная установка не перезаписывает пользовательские темы и звуки.
- В «Настройки → Оформление → Темы из папки» нажмите **Обновить список тем**, затем выберите тему. Формат UTF-8 JSON: `{"name":"Моя тема","a":"#73B5FF","b":"#425BCC"}`. Цвета изменяются без перезапуска; ошибочные файлы пропускаются.
