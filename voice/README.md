# Reload Assistant · общий голос

[Развернуть в Cloudflare Workers](https://deploy.workers.cloudflare.com/?url=https://github.com/goodmannq/reload-ai-updates/tree/voice-service/voice)

1. Создайте **свой** ключ на https://fish.audio/app/developers/get-started/ . Не помещайте его в репозиторий и не отправляйте его в чат.
2. Нажмите ссылку выше и разверните Worker в своём аккаунте. Укажите `FISH_API_KEY` как **Secret**. Если мастер не предложил поле: Worker → Settings → Variables and Secrets → Add → Secret, затем Deploy. R2 не требуется.
3. Откройте `/health` на выданном публичном HTTPS-адресе. `configured: true` означает только наличие ключа, а не подтверждение его действительности. Передайте разработчику только публичный адрес Worker для проверки и подключения приложения.

Сервис принимает только POST `/speak` с JSON `{ "text": "Добрый вечер, сэр." }` до 650 символов. Ответ — MP3. Озвучка через Fish Audio; один фиксированный голос и только модель `s2.1-pro-free`, без платного резервного варианта. Звук с микрофона не принимается. Сервер не записывает тексты и не кэширует аудио. Текст передаётся провайдеру; применимы его условия. Проверьте права на публичное использование выбранного голоса и условия бесплатного API для вашего проекта.

Открытый endpoint не является закрытым API: ограничение Origin не аутентификация. Учтены общие и индивидуальные лимиты: 30 000/5 000 символов за сутки UTC, 25/12 запросов в минуту. Для учёта сохраняются счётчики и суточный псевдоним IP, не IP и не текст. Ошибочные запросы провайдера тоже расходуют квоту. При превышении — 429, без перехода на платный тариф. Аккаунт и настройки плана у владельца; для отключения удалите секрет или Worker.
